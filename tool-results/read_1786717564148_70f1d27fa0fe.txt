    58→    58→# 2ndLife — Enterprise PRD + Engineering Execution Plan (v2)
    59→    59→
    60→    60→**Product:** 2ndLife · **Company:** NahaLabs (Pty) Ltd

    64→    64→
    65→    65→## 1. Product Definition
    66→    66→
    67→    67→2ndLife is a multi-tenant SaaS platform that finds revenue already inside a business's systems — inactive, stale, abandoned, unpaid or at-risk — and recovers it through intelligent, empathetic workflows (WhatsApp-first).
    68→    68→
    69→    69→Core question: *"Who already wanted to buy, pay, renew or continue — and what stopped them?"*
    70→    70→
    71→    71→Product loop: **Detect → Prioritize → Engage → Recover → Verify → Measure**
    72→    72→
    73→    73→Initial recovery categories: stale leads, abandoned quotes, unconverted opportunities, lapsed customers, missed renewals, unpaid invoices, failed payments, dormant customers, expired offers, at-risk recurring revenue.
    74→    74→

    76→    76→

    78→    78→- **GTM vertical #1 = South African funeral & micro-insurance** (this is what the approved mockups depict). A vertical is a *configuration package* (terminology: policy/premium/lapsed; offer rules; compliance copy), e.g. `src/modules/verticals/funeral-insurance/`, never a fork of core logic.
    79→    79→- Later segments (subscriptions, financial services, education, healthcare, retail, B2B, professional services) = additional config packages only.

  1271→  1271→### `src/lib/db/index.ts`
  1272→  1272→
  1273→  1273→```ts
  1274→  1274→import { drizzle } from "drizzle-orm/neon-http";
  1275→  1275→import { neon } from "@neondatabase/serverless";
  1276→  1276→import * as schema from "./schema";
  1277→  1277→
  1278→  1278→type DbClient = ReturnType<typeof drizzle<typeof schema>>;
  1279→  1279→
  1280→  1280→let _db: DbClient | null = null;
  1281→  1281→let _checked = false;
  1282→  1282→
  1283→  1283→function getDb(): DbClient | null {
  1284→  1284→  if (_checked) return _db;
  1285→  1285→  _checked = true;
  1286→  1286→  const url = process.env.DATABASE_URL;
  1287→  1287→  if (!url) return null;
  1288→  1288→  _db = drizzle(neon(url), { schema });
  1289→  1289→  return _db;
  1290→  1290→}
  1291→  1291→
  1292→  1292→export const db = new Proxy({} as DbClient, {
  1293→  1293→  get(_t, prop) {
  1294→  1294→    const client = getDb();
  1295→  1295→    if (!client) {
  1296→  1296→      throw new Error("DATABASE_NOT_CONFIGURED");
  1297→  1297→    }
  1298→  1298→    const value = (client as never as Record<string | symbol, unknown>)[prop];
  1299→  1299→    return typeof value === "function" ? value.bind(client) : value;
  1300→  1300→  },
  1301→  1301→});
  1302→  1302→
  1303→  1303→export const isDbConfigured = () => Boolean(process.env.DATABASE_URL);
  1304→  1304→```
  1305→  1305→
